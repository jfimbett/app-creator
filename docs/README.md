# docs/

This folder holds your product's documents. The `product-interview` skill creates them; the other skills keep them
current:

| File | What it says |
|---|---|
| `product.md` | customers, problem, main user journey, MVP features and exclusions, data, capabilities |
| `architecture.md` | stack, parts of the app, data model, external services, security, decision log |
| `acceptance.md` | checkable criteria, known-answer calculations, edge cases, permissions |
| `plan.md` | small slices in order, progress log, known problems |

Edit them yourself whenever your decisions change. Claude reads them at the start of each session.
